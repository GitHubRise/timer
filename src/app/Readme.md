# app — 应用外壳

进程入口、生命周期编排、托盘图标与右键菜单。把各模块组装成一个可运行的程序，本身不实现显示、格式解析或数据模型。

## 放什么

- `Program.cs`：单实例 Mutex、命名事件唤醒、未处理异常兜底、`Application` 启动。
- `AppController.cs`：加载设置、创建悬浮窗与托盘、菜单事件、天气定时刷新、防抖保存、设置窗口生命周期。
- `OverlayMenu.cs`：托盘与悬浮窗共用的右键菜单。

## 不放什么

- 悬浮窗绘制与拖拽 → `../clock/`
- 设置模型、设置窗口 → `../settings/`
- 提醒/日程规则 → `../reminders/`
- P/Invoke 与注册表 → `../platform/`

## 边界

- 只通过其他模块的公开成员与事件协作，不直接读文件、写注册表或调用 Win32。
- 所有 UI 操作回到 WPF Dispatcher 线程；后台线程只投递回调。
