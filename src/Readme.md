# src — 代码内容根

GameClock 的全部手写源码按业务内容域分模块放在本目录；`generated/` 只放构建产物。一级子目录统一用内容域这一根轴，不再按 `views/`、`services/` 这类技术层切分。

## 放什么

- 各模块的 `.cs` 源码，模块内可再按技术层细分（当前规模未触发）。
- `generated/` 中由 `build.ps1` 生成的版本信息。

## 不放什么

- 项目说明与构建命令 → 根 `README.md`、`AGENTS.md`
- 构建脚本、应用清单、运行配置、编译号 → 根 `build.ps1` 与 `../build/`
- 图标与矢量资源 → `../assets/`
- 长期文档与截图 → `../docs/`

## 边界

- 全部类型保持 `namespace GameClock`，模块靠目录与类型名前缀区分；这是避免全仓 using 连锁改动的取舍，已在 `../docs/300001-系统架构与模块契约.md` 登记。
- 不设 `utils/`、`common/` 这类无归属兜底目录；通用能力必须落到具体模块。
- 单个目录文件数超过 15 个时，再按技术层做第二级细分。
