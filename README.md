# 游戏时间悬浮窗（GameClock）

一个面向 Windows 10/11 的桌面时间悬浮窗。默认红色字体、`HH:mm:ss`（24 小时制）、UTC+08:00 时区、始终置顶，适合在无边框窗口模式游戏时查看时间。除 .NET 日期格式外，还支持“简洁变量”格式，可显示农历、干支、生肖和天气变量。

程序使用 C# / .NET Framework 4.8 编写，通过 Win32 API 实现置顶、鼠标穿透与分层透明窗口，不向游戏进程注入任何代码。

## 直接运行

运行 [dist/GameClock.exe](dist/GameClock.exe)。首次启动时默认在屏幕右上角显示，并在系统托盘创建蓝色科技表盘图标。

- 系统要求：Windows 10/11 64 位，.NET Framework 4.8（Windows 10 1903 及以上通常已内置）。
- 程序只使用当前用户权限，不需要管理员权限。

## 操作

| 操作 | 功能 |
| --- | --- |
| 按住左键拖动时间 | 移动位置，位置会自动保存 |
| 在时间上右键 | 打开与托盘完全相同的右键菜单 |
| 右键系统托盘图标 | 打开同一份菜单（穿透后靠它恢复） |
| 双击托盘图标 | 打开设置 |
| 再次运行 GameClock.exe | 如果程序已在运行，会打开现有程序的设置窗口 |

菜单包含：设置、鼠标穿透、始终置顶、当前状态（工作/娱乐）、重置位置、退出。

## 设置说明

设置窗口分为六个页签：**外观、任务栏、时间格式、定时提醒、日程、天气**。

### 外观

- 默认颜色为红色 `#FF3B30`，可从调色板快速选择，或用颜色对话框选择任意颜色。
- 可更换字体（列出系统中已安装字体，并在下拉项中预览字体本身）。
- 字号 16–160 px。
- 不透明度 20%–100%。
- 可单独开启/关闭文字阴影。
- 可开启 3D 立体字（1–3 层挤出效果，与阴影可同时开启）。
- 显示位置：可分别勾选「桌面悬浮窗」与「任务栏时钟」，两者至少保留一个。任务栏时钟覆盖在系统任务栏时间区域上显示，退出程序或取消勾选后恢复系统时钟。
- 窗口行为：鼠标穿透、始终置顶、开机自动启动。

### 任务栏

任务栏时钟与桌面悬浮窗**各自保存字体、字号、颜色和显示格式**，互不影响：

- 默认字体 `Microsoft YaHei UI`、字号 10 px、颜色 `#000000`；深色任务栏建议改为 `#FFFFFF`。
- 默认显示格式为两行：第一行 `yyyy-mm-dd HH:ff:ss`，第二行 `MD ddd rtm`（农历、星期与温度）。
- 格式使用简洁变量，支持两行；任务栏空间不足时自动缩小字号。
- 程序不会隐藏系统时钟，而是把它移出任务栏以保留布局占位，因此托盘图标不会移动；退出程序或取消勾选后系统时钟自动回到原位。

### 时间格式

默认显示 `HH:mm:ss`（24 小时制），默认时区为 **UTC+08:00（China Standard Time，中国标准时间）**。这里内置了大量常用格式，直接选择即可，无需手动修改：

- `HH:mm:ss`（默认，24 小时制）
- `hh:mm:ss`（12 小时制）
- 日期 + 时间、中文日期、星期、毫秒
- `yy` 两位年份，如 `yy-MM-dd HH:mm:ss`
- ISO 周数 `WW`，如 `yyyy年 第WW周 dddd`
- 两行布局：日期一行、时间一行
- 支持选择系统内的全球时区；切换后，时间、日期、周数和提醒触发均按所选时区计算，默认 UTC+08:00

自定义格式会实时预览，**不按回车也会更新**；按一次 Enter 可立即应用预览。最多支持一个换行，使用“插入换行”或 Ctrl+Enter 添加。`SSS` 会自动当作毫秒 `fff` 处理。

### 简洁变量（新增）

在“时间格式 → 格式语言”中可以切换两种格式语言，两种格式**分别保存、互不影响**：

- **兼容 .NET**：沿用上面的 .NET 日期格式，已有配置不受影响。
- **简洁变量（默认）**：使用下表的短变量，支持农历、干支、英文月份/星期和天气。

两种模式都内置了一组精挑的常用格式（约 20 个），重点覆盖“日期 + 时间 + 农历/星期/温度”等实际会用到的组合；“格式说明”支持关键词检索，一行一个变量，按“格式：描述。示例预览：预览”展示。

| 变量 | 含义 | 示例 |
| --- | --- | --- |
| `yy` / `yyyy` | 两位 / 四位公历年份 | 26 / 2026 |
| `YY` / `YYYY` | 中文数字年份 | 二六 / 二〇二六 |
| `nn` / `NN` | 生肖 / 干支+生肖 | 马年 / 丙午马年 |
| `m` / `mm` | 公历月（不补零 / 补零） | 10 / 10 |
| `M` | 农历月（含闰月） | 九月 / 闰六月 |
| `d` / `dd` | 公历日 | 30 / 30 |
| `D` | 农历日 | 廿一 |
| `h` / `hh` | 12 小时制小时 | 10 / 10 |
| `H` / `HH` | 24 小时制小时 | 10 / 10 |
| `f` / `ff` | 分钟（注意：不是 .NET 的 `f`） | 50 / 50 |
| `s` / `ss` | 秒 | 16 / 16 |
| `SSS` | 毫秒 | 345 |
| `ddd` / `dddd` | 中文星期 | 周五 / 星期五 |
| `EM3` / `EM` | 英文月份 | Oct / October |
| `EW3` / `EW` | 英文星期 | Fri / Friday |
| `week` | ISO 周数（含“第/周”） | 第44周 |
| `day` / `doy` | 年内第几天（含“第/天”） | 第303天 |
| `tt` / `TT` | 英文 / 中文上下午 | AM / 上午 |
| `\n` | 换行 |  |
| `"文字"` | 引号内原样输出 |  |

说明：

- `M` 是农历月、`D` 是农历日；公历月用 `m/mm`，公历日用 `d/dd`。输入 `MM`/`DD` 会直接报错并提示正确写法，避免静默出错。
- **两种模式的月份/分钟不同**：兼容 .NET 中 `MM` 是月份、`mm` 是分钟；简洁变量中 `mm` 是月份、`ff` 是分钟。
- 农历、干支和生肖使用 Windows 内置农历算法离线计算，不需要联网；时间按“显示时区”计算。
- 变量区分大小写；格式中的普通英文需要写在英文双引号里，例如 `"Week" week`。
- 天气变量也可以写进时间格式；一旦时间格式里出现天气变量，独立的天气行会自动隐藏。

示例：

```text
HH:ff:ss                         → 10:50:16
yyyy-mm-dd HH:ff:ss              → 2026-10-30 10:50:16
HH:ff:ss\nM D ddd                → 10:50:16
                                   九月 廿一 周五
NN · M D · week                  → 丙午马年 · 九月 廿一 · 第44周
TT hh:ff:ss                      → 上午 10:50:16
yyyy年mm月dd日 NN MD\nday week 今天 HH:ff:ss
                                 → 2026年10月30日 丙午马年 九月廿一
                                   第303天 第44周 今天 10:50:16
```

### 定时提醒

- 内置多条工作/娱乐提醒，点击按钮即可加入，例如“12:00 补充能量”“23:00 早点休息”。
- 首次启动默认已启用：
  - 工作状态：`09:30`、`12:00`、`18:30`
  - 娱乐状态：`12:00`、`23:00`、`01:00`
  - 其中 `12:00` 为工作/娱乐共用的提醒。
- 可自定义时间（`HH:mm`）、内容、适用状态。
- 每条提醒可单独启用/停用、修改时间和内容、删除。
- 支持**测试提醒**：自定义表单可点“测试”，已添加的每条提醒也可单独测试；悬浮窗会显示“测试提醒”卡片，不会触发真实提醒或修改计划。
- 提醒显示时长可配置为 **5 / 8 / 10 / 12 / 15 秒**，默认 12 秒。
- 支持**提醒闪烁次数**（0–20，默认 3）：提醒卡片进入时会闪烁，便于在游戏画面中注意到；**0 表示不闪烁**。
- 支持**闹钟铃声**：提醒出现时播放短促提示音；在设置中取消“提醒铃声”即可完全静音。
- 可开启**鼠标悬停关闭**：鼠标在提醒卡片上停留 3 秒即关闭；穿透状态下同样有效。
- 适用状态：全部状态、仅工作、仅娱乐。
- 当前状态可在此页或右键菜单中切换。只有匹配当前状态的提醒才会触发；提醒每天最多触发一次。
- 到点后，提醒会显示在时间下方 12 秒，同时发送托盘通知。存在多条时按顺序显示。

### 天气

- 默认开启，默认城市为**北京**。
- 数据来自 [Open-Meteo](https://open-meteo.com/) 公共 API（无需 API Key），默认每 **30 分钟**更新一次。
- 刷新频率可配置：每 10 分钟、20 分钟、30 分钟、45 分钟、1 小时、2 小时。
- 天气显示在时间下方，例如：`北京 · 晴 · 12°C · 今日 9°~17°`。
- 天气行的**字体、字号、颜色（含黑色）、粗体、倾斜、阴影**都可以独立于时间文字单独设置；修改后可在设置顶部实时预览。
- 可修改城市（支持中文、英文），保存或应用后立即刷新。
- 点击“**测试地名**”可只查询当前城市，验证地名是否解析成功；成功时会显示绿色 `✓`，失败时显示红色 `✕`，不会修改当前显示。
- 网络不可用或城市无法解析时，天气行自动隐藏，不影响时钟。

**天气格式（可选）**：在“天气 → 天气格式”中可以用简洁变量自定义整行，留空则保持默认的“城市 · 天气 · 温度 · 今日高低温”。

| 变量 | 含义 | 示例 |
| --- | --- | --- |
| `pos` | 城市 | 北京 |
| `we1`–`we6` | 第 1–6 天天气 | 晴 |
| `tl1`–`tl6` | 第 1–6 天最低温 | 6°C |
| `th1`–`th6` | 第 1–6 天最高温 | 19°C |
| `rtm` | 实时温度 | 17°C |
| `rhu` | 实时湿度 | 湿度45% |
| `rwd` | 风向 | 西北风 |
| `icn` | 天气图标 | ☀ |
| `aqi` | 空气质量（US AQI） | 优 49 |
| `ip` | 公网 IP | 221.222.190.200 |

示例：`pos · we1 · rtm · 今日 tl1~th1`、`icn rtm · rhu · rwd · aqi`。

- 6 日预报、湿度、风向来自 Open-Meteo；空气质量来自 Open-Meteo 空气质量接口（仅当格式使用 `aqi` 时请求）。
- 公网 IP 仅在格式使用 `ip` 时请求（`api.ipify.org`），结果缓存 6 小时；不使用该变量就不会发起请求。
- 天气变量也可以写在时间格式里，此时独立天气行自动隐藏，天气文字跟随时钟字体和颜色。

### 日程

- 新增“日程”页签，用于生日、纪念日、会议、机票等重要约定。
- 采用列表展示，顶部输入框可按标题、类型、日期、时间或备注实时筛选。
- 添加和编辑均使用弹框；可填写类型、标题、日期（`yyyy-MM-dd`）、时间（`HH:mm`）、提前提醒时间、备注。
- 启用/停用、编辑、删除操作均使用 SVG 矢量图标。
- 生日/纪念日可选择“每年重复”；会议/机票一般为一次性。
- 日程使用当前“显示时区”，到点后以“生日日程 / 会议日程 / 机票日程”等形式显示在悬浮窗，并沿用提醒的铃声、闪烁、显示时长和悬停关闭设置。
- 已添加日程可在列表中启用/停用、编辑、删除。
- 日程不会自动添加，首次启动时为空；需要在“日程”页自行添加。

## 保存与应用

设置窗口底部：

- **应用**：保存设置但不关闭窗口，立即更新悬浮窗。
- **保存并退出**：保存设置并关闭窗口。
- 右上角 `×`/Esc：关闭窗口；尚未应用的修改不会生效。

设置会保存到：

```text
%APPDATA%\GameClock\settings.json
```

异常日志：`%APPDATA%\GameClock\error.log`。

## 开机自启

在“外观 → 窗口行为”中勾选“开机自动启动（当前用户）”。程序会在当前用户注册表启动项中写入：

```text
HKCU\Software\Microsoft\Windows\CurrentVersion\Run
GameClock = "完整路径\GameClock.exe"
```

无需管理员权限。取消勾选并应用后会自动删除该启动项。

## 显示与兼容性说明

- 支持普通窗口、无边框窗口、窗口化全屏游戏。**独占全屏（Exclusive Fullscreen）游戏无法被普通窗口覆盖**，请在游戏内选择“无边框窗口/窗口化全屏”。
- 使用置顶窗口和 Win32 鼠标穿透，不注入游戏、不读取游戏内存，避免影响反作弊。
- 若游戏以管理员身份运行，而本程序没有，某些系统级输入/置顶行为可能受 UIPI 限制；可让两者以相同权限运行。
- 托盘图标是穿透后的恢复入口，请不要隐藏系统托盘。
- 任务栏时钟依赖系统任务栏窗口结构（`Shell_TrayWnd` / `TrayClockWClass`）。系统更新或任务栏重建后程序会自动重新定位；若任务栏异常，取消勾选或退出程序即可恢复系统时钟。
- 设置、位置和提醒的“今日已触发”状态都会保存；程序退出后不会继续提醒。

## SHA-256 校验

发布目录中的 `SHA256SUMS.txt` 包含以下文件的 SHA-256：

- `GameClock.exe`
- `GameClock.exe.config`
- `README.md`
- `GameClock-v1.1.zip`

PowerShell 校验方式：

```powershell
Get-FileHash .\GameClock.exe -Algorithm SHA256
Get-Content .\SHA256SUMS.txt
```

也可以使用系统命令：

```cmd
certutil -hashfile GameClock.exe SHA256
```

`SHA256SUMS.txt` 位于压缩包外部，因此可以校验压缩包本身。

## 第三方服务

- 天气、空气质量与地理编码：[Open-Meteo](https://open-meteo.com/)（免费公共 API，无需 Key）。
- 公网 IP（仅当格式使用 `ip` 变量时）：[ipify](https://www.ipify.org/)。
- 只发送城市名/坐标到天气服务，不包含账号或个人身份信息；公网 IP 查询不发送任何本机信息。
