# native — 原生组件

存放需要运行在宿主进程内的 C++ 组件。当前只有任务栏绘制组件：由 C# 端注入 `explorer.exe`，在系统时钟窗口上自绘两行文本。

## 放什么

- `taskbar/`：注入任务栏的 DLL 源码与构建说明。

## 不放什么

- WPF 界面、设置与业务逻辑 → `../src/`
- 构建产物（`GameClockTray.dll`）→ `../dist/`，不入库

## 边界

- 只编译为 x64、静态链接 CRT（`/MT`）的 DLL；不导出函数，加载即安装。
- 组件不得改变系统时钟窗口的位置、尺寸或可见性，只接管绘制并在超时/卸载时恢复原窗口过程。
- 由 `../build.ps1` 调用 `cl.exe` 编译；缺少 Visual Studio C++ 工具时跳过并给出警告。
