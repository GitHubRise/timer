# docs — 项目文档

GameClock 的长期文档库：架构说明、模块契约与界面截图。目录自述不占编号；正式文档按六位编号命名，规则见 `../../general-policies/general/docs-numbering.md`。

## 放什么

- `000000-全库总索引.md`：全库导航、大类与字母登记。
- `300000-架构与模块.md`：大类 3（设计与架构）索引。
- `300001-系统架构与模块契约.md`：启动链、模块职责、关键方法契约。
- `images/`：界面截图。

## 不放什么

- 临时笔记与草稿 → 工作区 `../../../temp/`
- 构建产物 → `../dist/`
- 用户使用说明 → 根 `../README.md`

## 边界

- 新增文档先定编号、再写正文、最后回填 `000000` 与对应大类索引。
- 编号一经发布不复用；废弃文档保留编号并在索引中标记状态。
