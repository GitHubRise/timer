| `timezone.png` | 时间格式页签中的时区选择 |
| `reminders.png` | 设置窗口「定时提醒」页签 |
| `default-reminders.png` | 内置提醒列表 |
| `reminder-duration.png` | 提醒显示时长选项 |
| `schedule.png` | 设置窗口「日程」页签 |
| `schedule-dialog.png` | 日程添加/编辑弹框 |
| `about.png` | 关于窗口 |

## 边界

- 只放界面截图，不放应用图标（`../../assets/`）或构建生成图。
- 界面改版后同步替换截图，并核对引用它的文档描述是否仍成立。
